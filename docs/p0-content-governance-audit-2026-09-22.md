# P0 콘텐츠 검사 완료 대조

검증일: 2026-09-22. 범위는 GOAL §12의 마지막 P0 기준과 §6·§11.3의 전송 전 검사/생략 표시다. 제품 코드를 다시 구현하지 않고 현재 호출 경로, 실제 요청 경계 검사, 격리 PostgreSQL 및 Chrome 결과를 대조했다.

## 판정 기준

- `content-guard.js`에서 거부한 내용은 의미 검사에도 전송하지 않는다. 로컬 검사를 통과한 내용의 의미 검사가 거부되거나 실패하면 후속 생성·게시를 진행하지 않는다.
- 이름·연락처·급여·대외비 등 일반 자료와 마스킹·환경 변수 참조·예제 표기는 사용자 지정 허용 기준을 유지한다. 모든 민감 정보를 탐지한다는 의미가 아니다.
- 키 없는 의미 검사 생략(`skipped=true`), 실제 검사 완료(`skipped=false`), 검사 장애(`unavailable=true`)를 구분한다. 키가 생겼다는 이유로 저장된 검사 결과를 바꾸지 않는다.
- AI 응답은 HTTP 전송 경계에서 모의 처리했다. 실제 모델의 판단 정확도와 실제 외부 서비스 호출 완료를 주장하지 않는다. DB와 브라우저·서버 액션은 실제 실행한다.

## 실행 결과

- 격리 DB를 활성화한 `bun run test`: **659 통과, 실패 0, 생략 0**. 기본 실행은 **136 통과, DB 22 생략**이다.
- `bun run check`: 오류 0·경고 0. `bun run lint`, `bun run build`, `git diff --check`: 통과.
- 새 `node tests/browser/governance-status.mjs`: **13개 묶음 통과**. 360/768/1440px·라이트/다크, JavaScript 없는 기본 화면을 포함한다.
- 생략 상태의 다섯 화면(편집·이력·토론·초안 상세/목록)은 조회만으로 AI를 호출하거나 데이터를 바꾸지 않았다. 키를 설정한 뒤에도 초안의 이전 생략 상태가 남고 명시적 재검사 후에만 갱신됐다.
- 선택 게시 결과의 생략 안내, 저장된 통합안의 생략 안내·키 없는 수동 적용, 토론의 로컬 차단/의미 거부/장애/재시도 및 입력·DB 보존을 확인했다. 페이지 오류와 실제 외부 HTTP는 0회다.
- 앞선 변경의 현재 회귀도 전체 659개 검사에 포함된다. 위키파이어의 실제 모달/업로드 생략 안내는 55회차 `relaxed-upload.mjs` **14개 묶음**의 추가 근거다.

실행 증거: `/tmp/wiki-viki-p0-governance-final-20260922/`의 `baseline-*.log`, `baseline-results.json`, `browser/results.json`과 화면 캡처. 위키파이어 추가 근거는 `/tmp/wiki-viki-security-audit-20260922/`의 `final-full-db.log`, `browser/browser-results.json`이다. 재실행 스크립트는 저장소의 `tests/`에 있다.

## 완료 범위와 남은 조건

**P0 전송 차단·검사 생략 기준은 완료했다.** GOAL의 해당 체크박스를 이 근거로 갱신한다. 기존에 완료한 다른 P0 기능을 새로 구현하거나 P1로 확장하지 않았다.

사용자가 신고한 특정 Excel 파일의 최초 실패 원인은 별도 미확인 상태다. 일반 XLSX 추출/저장과 모달 오류·재열기 보존은 구현·검증됐지만, 당시 파일의 확장자·오류 문구 또는 같은 조건의 비식별 재현 자료가 없어 동일 사례 해결까지 단정할 수 없다. 이번에 필요한 정보를 다시 요청했다. 전체 사용자 요청 완료 선언은 이 조건이 해소된 뒤 판단한다. 실제 외부 AI·원격 DB·운영 배포 검증은 이번 감사 범위에서 수행하지 않았다.

후속 반복 57에서 원본 XLSX가 제공되어 위 조건이 해소됐다. 실제 AI 생성의 공통 시간 초과를 재현·수정하고, 같은 첨부 파일의 실제 AI/브라우저/격리 DB에서 32개 초안 생성과 검토 진입을 확인했다. 최종 전체 테스트는 665개 통과했다. 상세 변경·증거·검증 구분은 [진행 기록의 반복 57](../RALPH_PROGRESS.md)에 있다.
