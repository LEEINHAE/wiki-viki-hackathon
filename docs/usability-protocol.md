# 처음 사용하는 구성원의 탐색 평가

목표는 10개 질문 중 8개 이상에서 30초 안에 적절한 게시 문서 또는 문단에 도달하는 것이다. 아래는 실행할 평가 계획이며, 사람의 수행 결과는 아직 수집하지 않았다. 자동 검색 검증으로 이 목표를 달성했다고 판단하지 않는다.

## 준비

- 전용 검증 DB에 보존형 `seed:prototype`으로 예시 게시 문서 6개와 초안 1개를 적재한다. 화면에 예시 표시가 있는지 확인한다. 이 자료는 승인된 운전·업무 기준이 아니다.
- 처음 사용하는 참가자가 읽기 계정으로 로그인한다. 기능 설명 없이 검색창 위치만 알려 준다. 질문마다 홈에서 시작하고 직전 검색어를 비운다.
- 질문을 읽은 뒤 입력을 시작할 때 시간을 재고, 참가자가 찾았다고 말하며 문서·문단을 지목하면 멈춘다. 30초를 넘으면 시간 초과로 기록한다. 정답을 알려 주거나 검색어를 대신 입력하지 않는다.
- 참가자의 실명·검색 본문은 기록하지 않는다. 익명 참가 번호, 화면 크기, 질문 번호, 시간, 도달 위치, 성공 여부와 필요한 사용성 메모만 남긴다.

| 번호 | 질문                                                                   | 판정할 문서·문단                    | 시간/결과 |
| ---- | ---------------------------------------------------------------------- | ----------------------------------- | --------- |
| 1    | RFCC는 어떤 역할을 하는 공정인가요?                                    | RFCC · 정의                         | 미측정    |
| 2    | CDU라는 약어의 문서를 찾아보세요.                                      | 상압증류탑                          | 미측정    |
| 3    | Regenerator의 한국어 문서를 찾아보세요.                                | 촉매재생탑                          | 미측정    |
| 4    | 산업단지 공급 스팀을 설명하는 문서는 무엇인가요?                       | 산단스팀                            | 미측정    |
| 5    | 설비 이상을 발견했을 때 참고할 예시 절차를 찾아보세요.                 | 정비 요청 프로세스                  | 미측정    |
| 6    | OEC라는 예시 항목은 어떤 문서와 연결되나요?                            | OEC에서 산단스팀으로 이동           | 미측정    |
| 7    | RFCC 촉매가 재생된 뒤 어디로 돌아가는지 찾아보세요.                    | RFCC · 정의의 촉매 순환 문단        | 미측정    |
| 8    | RFCC 부하 조정 전에 유틸리티 담당과 협의해야 한다는 문단을 찾아보세요. | RFCC · 운전 시 유의사항             | 미측정    |
| 9    | 상압증류탑 하부 잔사유와 연결된 후속 공정을 찾아보세요.                | 상압증류탑에서 RFCC로 이동          | 미측정    |
| 10   | 스팀 수급과 RFCC의 관계를 설명하는 문서를 찾아보세요.                  | 산단스팀 또는 RFCC의 스팀 수급 문단 | 미측정    |

모든 질문 종료 후 성공 수/10과 30초 이내 성공 수/10을 각각 기록한다. 실패 원인은 검색 결과 없음, 별칭 이해, 이동 경로, 문단 찾기, 화면 문제로 구분한다. 결과를 개선 사항과 함께 구현 기록에 추가한다.
