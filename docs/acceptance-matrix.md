# 로드맵 항목별 판정

기준: [제품 로드맵](product-roadmap-2026-09-21.md) §12–13. 2026-09-21의 코드와 이번 실행 결과를 대조했다. `완료`는 아래에 적은 검증 환경의 기능 판정이며, 연결된 운영 DB에 적용했거나 실제 배포를 마쳤다는 뜻이 아니다. 환경에 따른 미검증 범위는 별도로 남긴다.

검증 명령·화면 크기·데이터 보존 이슈는 [구현·검증 기록](implementation-progress.md)에 있다.

후속 사용자 요청에 따라 현재 로컬 개발 서버는 로그인 없이 이용하고, 일반 사내 정보에 대한 콘텐츠 차단을 검토 안내로 완화했다. 아래 인증·엄격한 콘텐츠 검사 판정은 기본/운영 정책 기준이다. 운영 빌드가 개발용 두 설정을 무시하고 인증과 `strict` 정책을 유지하는 HTTP 검증을 추가했다. 개발 완화 모드의 실제 AI 업로드 결과는 [별도 기록](relaxed-policy-verification.json)에 있다.

## 후속 사용자 요청

2026-09-22 관리자 기능 제거 요청은 원래 로드맵의 관리자 메뉴·작업 구성보다 우선한다. 수정 제안·검토/관리·정기 검토 메뉴를 제거하고 관리자 역할의 직접 조회·저장 요청도 403으로 비활성화했다. 저장된 기록과 다른 역할의 기능은 유지한다. 관리자 알림·역사의 제거된 화면 링크도 정리했다.

같은 날 사용자가 DB 통합 검증 생략을 명시했다. 실행 중이던 `test:auth --port=5187`은 종료 130으로 중단했으며 이번 변경의 통합 검증은 생략으로 판정한다. 최종 필수 검사에서 제외하며 이전 시점의 통과 기록과 구분한다. 현재 단위 검사 30개 통과·선택 DB 1개 생략, Svelte 오류·경고 0, 빌드 성공 및 실제 관리자 화면 확인을 완료했다.

서버 훅에서 발생한 접근 제한에도 공통 오류 안내와 홈 복귀를 추가했다. 360px 라이트/다크, Tab·Enter로 홈 복귀, 없는 경로의 HTTP 404 안내를 확인했다. 200% 확대와 실제 참가자 검증의 미완료 판정은 유지한다.

기본 메인 화면에 최근 시작된 토론 5건과 토론/문서 바로가기를 추가했다. 실제 브라우저에서 특정 토론 선택과 문서 이동, 관리자 메뉴, 360px에서 가로 넘침 없는 배치를 확인했다. 단위 검사 29개 통과·선택 실DB 1개 생략, Svelte 오류·경고 0, 빌드 성공.
